    Troubleshooting

    Scanner not connecting?
    • Verify server IP address is correct
    • Check network connectivity (ping {{ server_ip }})
    • Ensure port 5000-7000 is not blocked by firewall
    • Try different port within range
    • Restart InfoWedge app
    Scans not appearing in system?
    • Check Network Scanner is running in Monitoring dashboard
    • Verify scanner is using TCP (not UDP)
    • Check auth token matches if using JSON format
    • Look for error messages in server logs
    Discovery not working?
    • Ensure scanner and server are on same network
    • UDP port {{ discovery_port }} must be open
    • Some networks block broadcast packets
    • Manual configuration always works
